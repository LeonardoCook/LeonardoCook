## Currently Building

### CASify

<a href="https://casify.website">
  <img align="right" width="100" src="https://casify.website/favicon.ico" alt="CASify logo" />
</a>

CASify is a learning app for students using the TI-Nspire CX CAS calculator.

I started building it during my own Abitur preparation because I wanted a better way to learn and understand the calculator.

The app provides step-by-step explanations for calculator functions, and I'm continuously working on adding more features and expanding its content.

**Website:** [casify.website](https://casify.website)
